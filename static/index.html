Core Metrics
TSTR Predictive Accuracy Core
Train on Synthetic, Test on Real — measures ML substitutability
Trains models on real and synthetic separately, tests both on a real held-out set. Performance ratio = synthetic ÷ real score.
Good result: Ratio > 0.85. Below 0.70 indicates significant information loss.

Privacy Metrics

Core Metrics
Exact Match Detection Core
Checks if any synthetic row is identical to a real row
Direct detection of copy rows between synthetic and real data.
Good result: Match rate = 0%, risk = Low.
Membership Inference Attack Core
Classifier tries to distinguish synthetic from real — AUC near 0.5 is ideal
A Random Forest classifier distinguishes synthetic from real. AUC ≈ 0.5 = indistinguishable = low risk.
Good result: AUC 0.50–0.60. Above 0.75 indicates significant divergence.
Distance-Based Privacy (DCR / NNDR / IMS) Core
Nearest-neighbour distances detect memorised real records
DCR (Distance to Closest Record), NNDR (Neighbour Distance Ratio), IMS (Identity Matching Score) — detect over-memorisation.
Good result: All three passed.
›Advanced optional metrics
Text Privacy Detection (NER) Advanced
Identifies personal information in text columns
NER scans text for PERSON, LOC, ORG, email, phone entities. Compares entity density between real and synthetic.
Good result: Synthetic entity density lower than real (de-identified).
Anonymisation Risk (Anonymeter) Advanced
Inference, linkability, and singling-out risk assessment
Anonymeter framework evaluates attribute inference, linkability, and singling-out attacks.
Good result: Overall risk < 0.3, level = Low.
